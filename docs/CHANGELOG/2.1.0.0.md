# IslandCaller 2.1.0.0

本版本修复了先前版本的一些重要问题，请及时更新。

## 🚀 新增功能与优化

- [TTS] 新增 ClassIsland 与 OmniTTS 播报提供方选择，支持设置点名前后文并预览播报内容
- [点名] 支持自定义点名提醒时长 (#85)
- [点名] 新增可选的独立 IslandCaller 点名结果窗口
- [主题] 新增 LiquidGlass 主题
- [档案] 新增多档案管理和可视化编辑。
- [档案] 支持按当前课程自动选择对应名单
- [行动] 新增可通过 ClassIsland 自动化切换档案的行动 (#52)
- [数据] 支持将 IslandCaller 数据导出为 `.iscdoc` 数据包，与从数据包导入
- [悬浮窗] 新增完整、紧凑、Mini 三种布局
- [自动化] 将随机点名、启用/禁用悬浮窗和切换档案整理到 IslandCaller 行动菜单 (#59)
- [公平性] 优化本节课重复点名后的权重恢复曲线，改善连续抽取时的均衡性。

## 🐛 Bug 修复

- [悬浮窗] 修复悬浮窗触控拖动相关问题
- [悬浮窗] 修复悬浮窗小于 1.0 倍缩放时窗口尺寸和边框异常的问题。 (#43)
- [悬浮窗] 修复深色主题下悬浮窗内容可见性问题 (#67)
- [档案] 修复编辑档案后点名按钮被意外禁用的问题 (#80)
- [兼容性] 修复高级点名窗口背景透明导致内容难以辨认的问题 (#83)

> [!WARNING]
> LiquidGlass 主题仅供开发测试，存在严重的内存泄漏和 use-after-free 风险，可能导致 ClassIsland 崩溃甚至 Windows 蓝屏；请勿在教学或生产环境启用。
